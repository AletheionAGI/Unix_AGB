# Code of Conduct

## Expected behavior

Contributors and participants are expected to:

- communicate respectfully and directly;
- focus criticism on technical content and evidence;
- disclose conflicts of interest when relevant;
- avoid harassment, threats, discrimination, or personal attacks;
- respect security disclosure, licensing, privacy, and attribution requirements.

## Unacceptable behavior

Unacceptable behavior includes:

- abusive or discriminatory language;
- deliberate intimidation or harassment;
- publishing private or security-sensitive information without permission;
- misrepresenting research results, benchmarks, implementation maturity, or
  security guarantees;
- submitting work that knowingly violates third-party licenses;
- publicly disclosing an unpatched vulnerability without following the
  project's responsible-disclosure process.

## Research and security integrity

Unix-AGB is experimental security research. Claims about detection,
enforcement, isolation, state compactness, performance, or safety must be
supported by reproducible evidence. A proposed architectural control must not
be described as implemented or validated until corresponding code and tests
exist.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions,
or restrict participation when this code of conduct is violated.

For conduct, security, or licensing concerns, contact:
`contact@aletheionagi.com`.
