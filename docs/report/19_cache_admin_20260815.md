# Etapa 19 — Administração autenticada da cache

Data: 2026-08-15

## Entrega

- novo binário `agb-cachectl`;
- comandos `rotate`, `rollback` e `list`;
- exigência de `AGB_ADMIN_TOKEN` não vazio;
- rollback recusa sobrescrever cache ativa;
- nenhuma retenção automática destrutiva.

## Execução

```bash
AGB_ADMIN_TOKEN='token-fora-do-repositorio' \
  cargo run --bin agb-cachectl -- list var/policy-cache.jsonl
```

## Limitações

O token é uma barreira local mínima e ainda não é um sistema de identidade ou
autorização multioperador. A próxima etapa deve integrar o comando ao socket de
administração do daemon e registrar auditoria de quem solicitou a operação.
