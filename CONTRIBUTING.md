# Contributing

Unix-AGB is an experimental security research project created and maintained by
Felipe Maya Muniz / AletheionAGI.

The project does not currently accept unsolicited code contributions. Issues
that provide reproducible technical evidence, documentation corrections, or
responsible security reports may be considered. Funded research, integration,
and development partnerships require prior written agreement.

Before proposing work:

1. read `README.md`, `THREAT_MODEL.md`, and `ROADMAP.md`;
2. distinguish proposed behavior from implemented and tested behavior;
3. do not weaken namespace isolation, authorization-before-resolution, or the
   rule that state cannot expand base privileges;
4. include tests and update contracts when changing externally visible data;
5. disclose third-party code, data, models, and license obligations.

Participation does not imply equity, royalties, ownership, authorship, or
governance rights. Alternative arrangements exist only through a signed written
agreement.

Security issues must follow [SECURITY.md](SECURITY.md), not public issue
discussion.
